# 파이썬 실습 예제 모음

입출력, 사칙연산, 제어문, 자료구조, 함수, 파일 처리를 다루는 파이썬 초급 실습 예제 모음입니다. 수업 과제로 작성한 코드라 일부 프로그램은 한국어로 입력 안내와 출력 메시지를 표시합니다.

## 실행 환경

- Python 3.6 이상 (f-string 사용)
- 외부 패키지 불필요 — 표준 라이브러리(`math`, `os`)만 사용
- 실행: `python 파일명.py`

## 파일 구성

### 연습문제 1 — 입출력 · 사칙연산

| 파일 | 내용 |
|------|------|
| `p1-1.py` | 두 정수를 입력받아 사칙연산(+, -, *, /) 결과 출력 (`split()`, `format()` 두 방식) |
| `p1-2.py` | `math` 모듈을 이용한 수식 계산 (이차방정식 근, 원의 넓이, 지수함수, 정규분포 식) |

### 연습문제 2 — 자료구조 · 제어문

| 파일 | 내용 |
|------|------|
| `p2-1.py` | 두 리스트의 내적(각 원소 곱의 합) 계산 |
| `p2-2.py` | 딕셔너리로 학번·이름 저장 후 학번으로 조회 (`Fin`/`Quit`로 종료) |
| `p2-3.py` | 1~100 사이 숫자의 짝수/홀수 판별 |
| `p2-4.py` | 1~100 사이 숫자의 3의 배수 · 5의 배수 · 3과 5의 공배수 판별 |
| `p2-5.py` | 입력한 연도의 윤년/평년 판별 |
| `p2-6.py` | 2~100 사이 소수(prime) 출력 |

### 연습문제 3 — 함수

| 파일 | 내용 |
|------|------|
| `p3-1.py` | 가변 인자(`*nums`)와 연산자 옵션(`op`)을 받아 합/곱을 계산하는 `calc` 함수 |
| `p3-2.py` | 리스트의 최솟값·최댓값을 반환하는 `min_max` 함수 |
| `p3-3.py` | 문자열의 모음 개수를 세는 `count_vowel` 함수 |

### 연습문제 4 — 파일 처리

| 파일 | 내용 |
|------|------|
| `p4-1.py` | 파일을 읽어 각 줄에 줄 번호를 붙여 출력하고 `.sav` 파일로 저장 |
| `p4-2.py` | 파일의 문자 수 · 단어 수 · 줄 수 통계 출력 |
