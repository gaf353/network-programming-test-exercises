# 파이썬 실습 예제 모음

입출력, 사칙연산, 제어문, 자료구조, 함수, 파일 처리를 다루는 파이썬 초급 실습 예제 모음입니다. 수업 과제로 작성한 코드라 일부 프로그램은 한국어로 입력 안내와 출력 메시지를 표시합니다.

## 실행 환경

- Python 3.6 이상 (f-string 사용)
- 외부 패키지 불필요 — 표준 라이브러리(`math`, `os`)만 사용

## 실행 방법

각 파일은 독립적으로 동작하는 스크립트입니다. 아래처럼 실행하세요:

```bash
python test1.1.py
```

일부 스크립트(예: 파일 읽기 예제)는 실행 중에 값을 입력하거나 파일명을 입력받습니다.

## 구성

### 1 — 기초: 입력, 사칙연산, math 모듈

| 파일 | 설명 |
|------|------|
| `test1.1.py` | 두 수를 입력받아 합·차·곱·나눗셈을 출력합니다. f-string과 `str.format()` 두 가지 출력 방식을 함께 보여줍니다. |
| `test1.2.py` | `math` 모듈을 활용한 여러 계산: 수식 계산, 이차방정식 근의 공식, 원의 넓이, 지수 항, 가우스 형태의 함수. |

### 2 — 리스트, 딕셔너리, 반복문, 조건문

| 파일 | 설명 |
|------|------|
| `test2(1).py` | 두 리스트의 내적(dot product)을 계산합니다. |
| `test2(2).py` | 간단한 학생 명부: 학번과 이름을 딕셔너리에 등록한 뒤 학번으로 이름을 조회합니다. |
| `test2(3).py` | 1부터 100까지 각 숫자가 짝수인지 홀수인지 출력합니다. |
| `test2(4).py` | 1부터 100까지 숫자를 3의 배수, 5의 배수, 또는 둘 다인지 분류합니다. |
| `test2(5).py` | 입력한 연도가 윤년인지 평년인지 판별합니다. |
| `test2(6).py` | 2부터 100까지의 소수를 찾아 출력합니다. |

### 3 — 함수

| 파일 | 설명 |
|------|------|
| `test3(1).py` | `calc(*nums, op)` — 연산자에 따라 여러 개의 인자를 더하거나 곱합니다. |
| `test3(2).py` | `min_max(nums)` — 리스트에서 최솟값과 최댓값을 반환합니다. |
| `test3(3).py` | `count_vowel(s)` — 문자열에 포함된 모음의 개수를 셉니다. |

### 4 — 파일 입출력과 예외 처리

| 파일 | 설명 |
|------|------|
| `test4(1).py` | 텍스트 파일을 읽어 각 줄에 줄 번호를 붙여 출력하고, 그 결과를 `.sav` 파일로 저장합니다. 파일이 없으면 다시 입력받습니다. |
| `test4(2).py` | 텍스트 파일을 읽어 문자 수, 단어 수, 줄 수를 계산합니다. 파일이 없으면 다시 입력받습니다. |

## 참고

예제는 주제별로 묶여 있으며 난이도가 점점 올라갑니다. 기본 입출력과 계산에서 시작해 자료구조와 제어문, 사용자 정의 함수, 마지막으로 예외 처리를 포함한 파일 처리로 이어집니다.
